# VkusnoKeitering

VkusnoKeitering Web site
Есть папки build-js(в нее компилируются из js) и build-css(в нее компилируются из css) в папке src - в них компируются скрипты и стили как при использовании dev server (gulp server), так и когда идет сборка (gulp scripts-build и gulp styles-build), отдельная папка build не создавалась, така как assets и html страницы не изменялись и они будут на движке(нужны только обработанные скрипты и стили)
